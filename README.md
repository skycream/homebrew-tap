# Sorimac Homebrew tap

```
brew install --cask skycream/tap/sorimac
```

[Sorimac](https://sorimac.com/en/) is an on-device dictation app for Mac: speak, and the text appears at your cursor in any app. $9.99 once, use it forever. 3-day free trial. Apple Silicon, macOS 15+.

Questions: support@sorimac.com
